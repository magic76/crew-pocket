Crew Helper Privacy Policy

Last Updated: September 2, 2026 · Applies to Crew Helper Mobile Application

🛡️ 1. 隱私權概述與承諾

歡迎使用 Crew Helper（以下簡稱「本應用程式」）。我們極度重視您的隱私權與個人資料安全。本隱私權政策旨在清楚向您說明本應用程式如何處理、傳輸及保護您在使用各項 AI 輔助與語音控制功能時的相關資訊。

核心隱私承諾：本應用程式絕不會販售、租借或將您的任何個人資料提供給第三方廣告商，亦不內建任何第三方追蹤或廣告推播 SDK。

🛡️ 1. Privacy Overview & Commitments

Welcome to Crew Helper ("the Application"). We are deeply committed to protecting your privacy and personal information. This Privacy Policy clearly outlines how the Application collects, processes, transmits, and protects your information when you use our AI voice assistant and device automation services.

Core Privacy Pledge: We do NOT sell, lease, or distribute your personal data to any third-party advertisers. The Application contains NO third-party advertising or telemetry trackers.

⚙️ 2. Android 無障礙服務 (AccessibilityService API) 顯著聲明

本應用程式使用 Android AccessibilityService API 來提供核心的智慧螢幕感知與免動手語音輔助操控功能。

  • 使用目的：讀取當前螢幕上的可見 UI 元素（如按鈕標籤、文字內容），使 AI 語音助理能夠理解您所看見的畫面，並在您發出明確語音指令時（例如「點擊確認」、「往下滑」），代替您執行點擊、滑動與輸入。
  • 嚴格的安全邊界：
    • 絕不收集、記錄或傳輸任何密碼、信用卡資訊、銀行帳號或驗證碼（OTP）。
    • 非主動監控：僅在您主動喚醒或進行語音對話並授權時進行即時節點檢索。
    • 絕不用於變更使用者設定或阻止使用者停用任何應用程式。
  • 使用者完全控制權：無障礙權限完全由使用者自主決定。您隨時可於系統「設定 > 無障礙」中隨時關閉或撤銷授權。
聲明：我們絕不會透過 Accessibility API 收集個人敏感識別資料並儲存於遠端伺服器。

⚙️ 2. AccessibilityService API Prominent Disclosure

The Application utilizes the Android AccessibilityService API solely to provide hands-free voice automation and on-screen contextual perception.

  • Purpose of Use: To inspect visible on-screen UI components (such as button labels, descriptions, and text fields), allowing the AI voice model to understand your current screen context and perform precise taps, scrolls, or text entries only upon your explicit voice commands (e.g., "Tap Submit", "Scroll Down").
  • Strict Safety Boundaries:
    • NEVER collects, stores, or logs sensitive user information such as passwords, payment cards, banking credentials, or two-factor authentication (OTP) codes.
    • No passive surveillance: UI elements are inspected ephemerally only during active voice sessions upon your request.
    • Never modifies system security settings or prevents users from disabling any applications.
  • User Sovereignty: You retain full control and can enable or revoke the Accessibility permission at any time via Android Settings > Accessibility.
Declaration: No personal or sensitive data inspected via the AccessibilityService API is retained or harvested for profiling or remote server storage.

🎙️ 3. 麥克風與音訊資料處理

當您啟動語音通話或使用浮動語音泡泡時，本應用程式會存取麥克風（RECORD_AUDIO / FOREGROUND_SERVICE_MICROPHONE）：

  • 即時串流：麥克風擷取的 PCM 音訊會透過加密安全通道（WSS / TLS）直接串流傳送給 Google Gemini Live 服務進行即時語音對話與意圖辨識。
  • 即時處理與不存檔：語音資料僅於對話期間即時串流傳輸，本應用程式在本機不會錄音並保存為音訊檔案。
  • 語音打斷感知：本地端即時演算法僅計算輸入音訊能量（RMS）以達成零延遲打斷 AI 回覆，計算完畢即拋棄。

🎙️ 3. Audio & Microphone Data Processing

When you start a voice session or interact with the floating bubble, the Application requests microphone access (RECORD_AUDIO / FOREGROUND_SERVICE_MICROPHONE):

  • Realtime Streaming: Captured PCM audio is streamed over encrypted secure protocols (WSS / TLS) directly to Google Gemini Live API for low-latency bidirectional voice communication.
  • Ephemeral Processing: Audio streams are strictly processed in realtime. The Application does NOT record, store, or archive your voice recordings on device or external storage.
  • Local VAD (Voice Activity Detection): Local RMS voice energy calculations are computed in memory solely for instant interruption capability and immediately discarded.

📸 4. 相機與螢幕截圖

  • 相機權限（CAMERA）：僅在您明確要求 AI「看看我周圍」或開啟實體相機預覽時啟動，影像透過加密傳輸至視覺模型進行即時分析。
  • 螢幕影像：僅在無法透過 Accessibility 語意節點辨識畫面時，依您的要求截取當前畫面片段供視覺模型解答，處理完畢即銷毀。

📸 4. Camera & Screen Capture

  • Camera (CAMERA): Activated ONLY when you explicitly prompt the AI to observe your physical surroundings or launch visual assistant mode. Visual frames are transmitted via TLS to the vision model for realtime recognition.
  • Screen Captures: Acquired ephemerally only when semantic UI nodes are unavailable to provide multimodal context, and discarded immediately after processing.

🔑 5. API 金鑰與本機設定儲存

本應用程式採用 **BYOK (Bring Your Own Key)** 自備金鑰架構：

  • 您所輸入的 Google Gemini API Key 會妥善保存在您手機本機的專屬加密 SharedPreferences 容器中。
  • 金鑰僅用於您的裝置向官方 Google API 建立連線，絕不上傳至任何未經授權的第三方伺服器。

🔑 5. API Keys & Local Storage

The Application utilizes a **BYOK (Bring Your Own Key)** architecture:

  • Your Google Gemini API Key is saved securely within the Application's private on-device SharedPreferences container.
  • The key is used solely to authenticate direct calls between your device and official Google API endpoints, never uploaded to third parties.
