口袋指揮超能力功能錦囊

Termux 行動端專屬強大能力全覽
🎙️1. Gemini Live 語音助理

即時雙向通話，支援音色、個人 Prompt、聲紋門檻、插話策略與通話保護；可視情況帶入最近主對話脈絡。

✓2. Live 委派主對話

Live 中明確交辦工作時，會直接把整理後的訊息送給目前 Role；Role 忙碌時會排入該 Conversation 的 queue。

📷3. 相機與手機感知

明確要求時才讀取目前螢幕或拍攝實體環境；Live 可擷取當下相機畫面交給主對話，避免誤用舊照片。

🧠4. 對話保存與記憶整理

一般 /compact 保留當前關鍵狀態以繼續工作；任務接近完成時可用 /compact-max，只留重要交接並降低 Context。

📲5. Android APK 主介面

APK 直接連線本機 Crew Runtime；更新程式後重新啟動即可讀取最新介面，不再依賴 PWA Service Worker 快取。

🧰6. 行動工作台

瀏覽 Termux 檔案、管理對話與媒體空間、執行程式碼，並可在對話中直接預覽 HTML、圖表與 Google 地圖導航。

🌐1. 原生無縫內嵌沙盒 2.0 (HTML / SVG / Chart.js / Web Audio)

請 AI 製作互動小工具、數據圖表或遊戲，系統會直接在對話氣泡內滿版動態渲染，高度自適應，點擊右上角【全螢幕】可另開新分頁操作，點【代碼】可一鍵複製。

🐍2. Python / Bash 後端即時直譯執行 (Termux 算力)

演算法計算、正則解析、磁碟巡檢（df -h）或腳本處理，點擊代碼右上角【執行】秒出結果。

🗺️3. Google 地圖導航與景點卡片

推薦餐廳、旅遊行程或交通路線時，AI 會生成一鍵喚醒 Google 地圖 App 的導航卡片，並在新分頁獨立開啟，不中斷對話。

📱4. 手機硬體原生整合 (GPS / 震動 / 雙向語音 / 相機)

支援手機相機拍照秒壓縮上傳、中文語音輸入辨識（STT）、語音合成朗讀（TTS）、Gemini Live 雙向語音對話與觸覺震動回饋。

⚡5. 專業快捷指令 (/compact, /btw, /plan, /goal)

在輸入框輸入 / 即可快速呼叫：記憶精簡提煉（/compact）、順帶一提（/btw 支線卡片）與自主目標規劃（/plan）。

📐6. 滿版極致視野 ＆ 賽博朋克思考跑馬燈

全新頂部抬頭設計釋放 100% 手機螢幕水平寬度，AI 思考推理與工具呼叫過程透過底部跑馬燈即時視覺化呈現。
