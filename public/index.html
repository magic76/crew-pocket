Antigravity 超能力功能錦囊

隨身 AI 與掌上開發工作台秘笈
📊 瀏覽器 JS & Chart.js 即時渲染 零延遲

只要讓 AI 輸出 JavaScript 代碼，點擊右上角【🌐 瀏覽器渲染】，手機螢幕將直接畫出互動折線圖、圓餅圖、Canvas 動畫或 Web Audio 音效！

Prompt 範例：「幫我用 Chart.js 畫出本週預算分配圓餅圖」
⚡ Python / Node / Bash 一鍵沙盒 50ms 秒跑

所有代碼塊均有【▶️ 執行】按鈕。點擊後直接在 Termux 本機調度直譯器執行，下方秒展開黑色終端印出 Output，零 Token 消耗。

Prompt 範例：「寫一段 Python 計算房貸每月還款金額」
🌐 HTML / SVG 產物獨立沙盒 全螢幕預覽

AI 輸出的 HTML/SVG 會自動轉換為美觀卡片。點擊【開啟預覽】可全螢幕操作微型網頁，或展開對話內小窗直接互動。

🗺️ Google 地圖一鍵導航 & 手機硬體 隨身必備

問旅遊/餐廳/景點時，AI 會主動附上一鍵導航卡。點擊【地鐵/步行導航】直接從您當前 GPS 位置喚醒 Google Maps 開始導航！亦支援手機震動、電量檢測與 GPS 定位。

Prompt 範例：「推薦附近景點並附上 Google 地圖導航卡片」
📱 Android 懸浮小窗與懸浮球 多工必備

在手機「多工任務畫面」中，長按 Antigravity 圖示選擇【以彈出視窗檢視】，即可縮小成懸浮泡泡，邊滑其他 App 邊叫出 AI！

/grill-me: 透過提問對齊需求
/schedule: 定時提醒排程
